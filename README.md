# Immersive 沉浸模式

为思源笔记提供简洁、可恢复的沉浸工作区。插件只调整界面显示，不移动或重建文档、侧栏和编辑器；重启后默认保持普通模式。

## 核心功能

- **完全沉浸**：隐藏顶部栏和四周 Dock，工作区保留 8px 留白、圆角与主题色淡描边。
- **悬浮功能卡片**：通过可拖动的小圆球访问已打开页签，以及左侧栏、上侧栏、右侧栏、下侧栏功能；空分组自动隐藏。
- **页签收纳**：当前页签使用与菜单行等宽的整行选中背景；悬停页签可通过红色 `×` 单独关闭。默认展示数量可设置为 1–20，超出部分折叠显示。
- **原生功能复用**：动态读取思源及已启用插件的实际入口，沿用原按钮、菜单和事件，不复制业务逻辑。
- **窗口与退出控制**：Windows、Linux 和 macOS 客户端使用卡片底部的四按钮 Dock，集中显示退出沉浸及三个窗口操作；Web 和 Docker 仅在卡片标题右侧显示退出按钮。
- **桌面顶栏模式**：可选择保留 28px 顶栏，将工具和原生页签融合到同一行；适用于 Windows、Linux 和 macOS 桌面客户端。
- **自动进入**：可选在思源界面启动完成后自动进入沉浸模式，默认关闭。
- **安全恢复**：退出、禁用或初始化失败时清理插件样式和事件，恢复原生布局及窗口状态。

进入与退出沉浸图标统一使用 Things 风格的主题蓝，在亮色、暗色主题下均保持清晰。

## 使用方法

- 点击顶栏沉浸图标，或按 **Alt+Shift+I** 进入/退出。
- 鼠标移入小圆球展开功能卡片；触摸设备使用点击。
- 拖动小圆球可调整位置，松开后自动贴边并保存。
- 点击外部或按 **Esc** 收起卡片。
- 无法识别的第三方入口可通过卡片中的 **原生工具栏（手动展开）** 访问。

## 插件设置

入口：**小圆球 → 插件设置**。

- **桌面客户端：保留顶部工具栏**：在桌面客户端保留融合后的工具与页签。
- **启动思源时进入沉浸模式**：思源界面启动完成后自动进入。
- **页签默认展示数量**：设置功能卡片默认显示的页签数。

设置即时保存。开启桌面顶栏后，卡片不会重复展示上侧栏功能、页签区和窗口控制 Dock。

## 安装

1. 将发布包解压到 `<工作空间>/data/plugins/siyuan-plugin-immersive-mode/`。
2. 确认目录内直接包含 `plugin.json`、`index.js` 和 `icon.png`。
3. 重启思源，在 **设置 → 集市 → 已下载 → 插件** 中启用 **Immersive 沉浸模式**。

发布包：`artifacts/siyuan-plugin-immersive-mode-1.0.0.zip`。

## 兼容与恢复

- 支持思源桌面端和桌面浏览器端；Windows 顶栏与窗口按钮仅用于本地 Windows 客户端。
- 不支持移动端。个别依赖非标准事件的第三方插件可能需要使用“原生工具栏”入口。
- 出现异常时可按 **Alt+Shift+I**、执行命令“切换沉浸模式”，或禁用插件；重启不会自动进入沉浸模式。
