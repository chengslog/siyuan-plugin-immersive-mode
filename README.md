# 沉浸模式 · 0.1.0 测试版

独立的思源插件。每次启动保持普通状态，不自动最大化或进入系统全屏，不移动或重建笔记和侧栏。

## 安装测试

1. 先禁用旧插件的沉浸功能，避免两套布局样式冲突。
2. 在思源 **设置 → 关于** 确认当前工作空间路径。
3. 将测试包解压到 `<工作空间>/data/plugins/siyuan-plugin-immersive-mode/`。目录下直接包含 `plugin.json`、`index.js`、`icon.png`，不要多套一层目录。
4. 重启思源，在 **设置 → 集市 → 已下载 → 插件** 中启用“沉浸模式”。更新后可禁用再启用。
5. 点击顶栏沉浸模式图标（方框内向外箭头），或使用 **Alt+Shift+I** 切换。退出使用方框内向内箭头。

测试包：`artifacts/siyuan-plugin-immersive-mode-0.1.0.zip`。也可以复制 `dist/` 内所有文件到插件目录。浏览器端安装到服务器对应工作空间后刷新浏览器。

## 完全沉浸与保留顶栏

设置路径：**小圆球 → 插件设置 → Windows：保留顶部工具栏**。

- 默认关闭：完全沉浸。隐藏整个顶部栏；工具、插件入口和页签收进小圆球，窗口控制位于一级卡片底部。正文顶部保留 8px 外侧留白，作为隐形原生拖窗区。
- 开启：工具按钮与原生标签合并到同一行，不在正文内占第二行；菜单不再重复收纳上侧栏功能。
- 仅保留顶栏模式使用 **28px** 顶栏，向下偏移 4px，在顶部区域居中；透明背景与工作区底色融合，无独立阴影或底部横线，窗口按钮同步收窄。
- 保留顶栏时，空白区声明为原生拖窗区，按钮、标签和输入控件不参与拖窗。完整顶栏右端另保留 48px 空白；原生“+”保留，页签切换按钮只在标签溢出时显示。完全沉浸的隐形拖窗区只占顶部留白，不覆盖正文或侧栏。
- 使用原生窗口按钮、标签节点、父节点和事件，不调用私有窗口桥接，不强制改变窗口状态。最大化 / 还原显示跟随宿主，多分屏标签按可用宽度分配。
- 此设置只对本地 Windows 桌面客户端生效。浏览器 / Docker / 其他系统不显示窗口控制条，即使同步了 Windows 偏好也不启用。

顶部悬停条已移除，鼠标靠近顶部不会触发弹出。

## 小圆球卡片

- 苹果辅助触控风格白色圆点：半透明灰底和同心光圈，闲置淡化、悬停 / 激活变清晰，可拖动贴边并保存位置。
- 鼠标移入悬浮球自动展开卡片，不抢走编辑焦点；点击外部或按 Esc 收起，触摸仍通过点击打开。
- 保持“左侧栏 / 上侧栏 / 右侧栏 / 下侧栏”的单列分组列表。组内顺序跟随思源原栏位：上栏、下栏从左到右；左栏、右栏从上到下。不是网格布局，也不按内置功能清单排序。
- 悬停主菜单、插件管理等有二级菜单的入口约 180ms，真实原生菜单在主卡片外侧展开，也支持点击；移入子卡片继续操作，保留原菜单选项、禁用状态及嵌套事件。文档树、智能体等侧栏入口仍需点击并直接调用原逻辑，不因悬停打开侧栏。未声明菜单的第三方命令不自动执行；首次点击确认确有原生菜单后才支持悬停。
- 一级卡片宽 280px、最大高 480px；二级和更深卡片保持宽 230px。一级采用与二级相同的正文 11.5px、行高 16px、内边距 5px 7px、10px 圆角和实色背景，分组及来源文字也加大到 11.5px。整行与窗口按钮悬停统一使用柔和背景，不显示彩色指示线或醒目红绿底色；Dock 保留原生选中状态，用柔和背景标识。移入另一个项目、页签区、插件设置或底栏时收起旧二级卡片，移入子卡片则保持展开。
- 二级菜单先按窗口可用高度计算，再向上避让底边；更深菜单也自动向上调整。超长菜单滚动展示，保持原生选项与事件，关闭后恢复原定位。
- 菜单名称、卡片标题和二级菜单不显示快捷键提示，原快捷键功能不变。“同步”固定名称，悬停展示思源最新同步信息，点击仍执行原生同步。
- 进入、退出沉浸采用用户提供的 SVG；底部窗口图标使用思源 iconMin / iconMax / iconRestore / iconClose，插件设置使用原生 iconSettings 齿轮，均随主题颜色变化。
- **取消“常用”及所有星标**，卡片上方改为已打开页签。当前页签高亮，点击直接切换原页面。
- **页签默认展示数量** 可设 1–20，默认 5。按原标签顺序展示，超出部分点击“展开其余页签”查看，再点“收起页签”折叠；重新打开菜单恢复设置数量。折叠不关闭页面。
- 页签区与功能列表分别滚动，“插件设置”位于功能列表末尾。退出沉浸、最小化、最大化 / 还原、关闭窗口固定在一级卡片底栏，四个 26×26px 正方形按钮均匀分布，随卡片显示与收起，不在窗口右上角创建控件。底栏不随菜单内容滚动，图标 15px。窗口操作只调用原生按钮，不搬移节点；关闭行为跟随宿主设置。浏览器 / Docker 底栏仅有退出沉浸。
- 没有可用入口的组不显示，同一入口不重复。
- 删除“页面与设置”及其两个重复入口。页面工具仍默认在正文原位置显示；宿主设置通过原生主菜单访问，“插件设置”打开本插件设置。
- 页签新增、关闭、改名、选中状态变化会刷新卡片；正文编辑不触发导航重建。保留完整顶栏时，悬浮卡片隐藏页签区及底部控制按钮，仅保留分组功能和插件设置。
- 球位置、Windows 开关、页签数量和资源自动进入开关独立持久化。旧收藏字段仅兼容保留，不再改变分组或生成常用区。

一级卡片横向留白为 12px，按钮内部再保留 7px；不显示原生 / 插件来源标签。插件设置仅保留 Windows 顶栏、页签数量、资源自动进入三项。开启“资源打开时进入沉浸模式”后，新打开文档、附件或其他资源页签时自动进入；默认关闭，启动恢复的已有页签、切换页签、编辑正文与移动页签不会触发，手动退出后等待下一次新开资源。

保留顶栏时，进入前记录原生页签起点，进入后保持相同横向位置；窗口缩小或工具增多时按可用空间避让，不覆盖原生按钮。顶栏沉浸图标为 14px，随模式切换思源原生提示，不再叠加浏览器 title 提示。设置窗口按内容收紧，开关与标题同排，说明精简，设置即时保存。悬浮菜单页签区和底部按钮区不再用分割线隔开，保留中间独立滚动。

## 面板与收纳范围

工作区四周保留 8px 留白。左右 / 底部面板及正文容器统一四边 1px 主题色淡描边，移除中心包装层重复边框，保留圆角与内容内边距。浮动 Dock 使用相同留白：Windows 控制条下方从 y=36 开始，否则从 y=8 开始。清除隐藏工具栏模式下侧栏多余的 42px 顶部占位。

不移动、关闭或重建文档树、Things、大纲、智能体及编辑器。退出、禁用及进入失败时撤销插件样式、布局标记、观察器和事件，不回写宿主布局或窗口状态。

动态识别原生 / 插件真实可用入口。Dock 按当前实际位置归类，左右竖栏第三个图标区属于底部面板，第二个仍属于相应侧栏。被其他收纳器移动的入口参考宿主归属和插件注册信息，未知位置单列“其他 Dock”，不猜测。

范围包括参考图中 7 个原生顶栏工具、9 个 Dock 及已启用插件。100% 缩放下隐藏的 Zoom 仍收纳其可用原生按钮；不存在、移除、禁用的入口不虚构。底部状态栏纯状态文字不混入 Dock 功能。

## 备用入口与恢复

**原生工具栏（手动展开）** 仅在主动点击时临时显示，用于访问无法识别的工具；点击其他位置或 Esc 收起。Windows 完整顶栏已开启时不重复显示这个入口。完全沉浸默认不会自行展开工具按钮。

第三方插件若异步测量、依赖 `isTrusted` 或仅处理 `mousedown`，可能需要手动工具栏；没有稳定 ID 的非标准顶栏入口不自动收纳。原生通知不隐藏。移动端不支持。

异常时先按 **Alt+Shift+I**，或在命令面板执行“切换沉浸模式”，或禁用插件；重启默认普通界面。

## 建议验收

1. 打开笔记及左右业务面板进入完全沉浸：四边描边、圆角留白协调，侧栏无顶部空块，顶部无可见栏。
2. 鼠标移到悬浮球，检查功能卡片自动展开；非最大化窗口拖动顶部空白区；不要用浏览器模拟代替系统操作验收。
3. 打开超过 5 个页签，展开 / 收起并切换；默认数量改为 3，重新打开菜单及重新启用插件检查保存。
4. 保留顶栏开启后，确认标签与工具共用 28px 一行、菜单无上侧栏；关闭后回到完全沉浸。
5. 拖球、缩小窗口、滚动功能列表，确认页签区与退出可访问；连续切换 10 次后禁用插件，原布局应恢复。

Node.js 22+，执行 `npm ci`、`npm run check`。当前 65 项模拟自动化测试，另有 Chromium 模拟宿主页布局检查，不等于真实 Windows 客户端及所有主题兼容性验收。记录见 `TESTING.md`，入口核对见 `FUNCTIONS.md`。
